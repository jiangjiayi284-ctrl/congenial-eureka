# 姜佳仪的个人官网

前端源文件位于 `site/`，GitHub Actions 自动部署到 GitHub Pages。

访问：https://jiangjiayi284-ctrl.github.io/congenial-eureka/

本地预览：`python3 -m http.server 8000 --directory site`

GitHub Pages 为静态托管，线上助手使用官网资料回答；DeepSeek 自主对话需配置独立后端，可通过 `window.PERSONAL_SITE_CHAT_ENDPOINT` 指定地址。不要把 API 密钥提交到仓库或浏览器代码中。

字母动画使用 boknows-text-image，MIT 许可随素材保留。
